# بررسی دامنه آزاد .ir

ابزار وب برای چک کردن وضعیت دامنه‌های `.ir` (آزاد یا ثبت‌شده).


## ویژگی‌ها

- رابط کاربری فارسی و RTL
- پشتیبانی از چند دامنه همزمان
- نمایش نتیجه به صورت جدول
- تاخیر بین درخواست‌ها برای جلوگیری از بلاک شدن

## نحوه استفاده

1. دامنه‌ها را یکی در هر خط وارد کنید (مثال: `test.ir`)
2. روی دکمه **شروع اسکن** کلیک کنید
3. نتیجه نمایش داده می‌شود:
   - **آزاد** → دامنه قابل ثبت است
   - **ثبت‌شده** → دامنه قبلاً گرفته شده
   - **خطا / نامشخص** → مشکل در ارتباط یا پاسخ نامعتبر

## فعال‌سازی GitHub Pages

برای اینکه ابزار به صورت آنلاین در دسترس باشد:

1. برو به Settings ریپو
2. از منوی سمت چپ **Pages** را انتخاب کن
3. در بخش Source گزینه **Deploy from a branch** را بزن
4. Branch را روی `main` و فولدر را روی `/ (root)` بگذار
5. Save کن

بعد از حدود یک دقیقه لینک زیر فعال می‌شود:

**https://lion0098.github.io/ir-domain-checker/**

## نکته فنی

این نسخه از endpoint وب `whois.nic.ir` استفاده می‌کند و برای دور زدن محدودیت CORS مرورگر از پروکسی عمومی استفاده شده است. ممکن است گاهی پروکسی کند یا موقتاً قطع باشد.

نسخه اصلی پایتون (socket مستقیم به whois.nic.ir) دقیق‌تر است.
